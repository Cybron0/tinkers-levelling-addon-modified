# tinkers-levelling-addon-modified
This is a modified version of Tinkers' Levelling Addon 1.20.1 by Pyre.

This version is primarily intended for use in a modpack I'm currently developing. As such, it may depend on Construct's Casting and other mods, and might not function correctly without them.

I don't intend to actively maintain this fork once it works with my modpack. If you encounter issues, please don't expect support or fixes from me. Please also avoid directing bug reports or support requests to the original developer, as this is an unofficial modification that I won't be maintaining either.

I'm not an experienced Java developer, so some of my implementations may be inefficient, contain bugs or cause unexpected compatibility issues. Use at your own risk.
