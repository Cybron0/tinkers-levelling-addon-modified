# Tinkers' Levelling Addon – Modified Source

This repository contains a modified source folder from **Tinkers' Levelling Addon for Minecraft 1.20.1**, originally developed by [Pyre540](https://github.com/Pyre540/tinkers-levelling-addon).

## Purpose

These modifications are primarily intended for use in a modpack I'm currently developing. They may depend on Construct's Casting and other mods, and are not intended to function as a standalone mod.

## Usage

This repository does not contain a complete mod project or a compiled JAR. It only contains the modified Java source folder.

To use these modifications, clone or download the original project and replace its corresponding folder:

`src/main/java/pyre/tinkerslevellingaddon/`

with the folder provided in this repository.

The modified project must then be compiled using the original project's build setup. Simply copying the `.java` files into an existing mod installation will not work, as Java source files need to be compiled into `.class` files first.

**Original project:** [Tinkers' Levelling Addon by Pyre540](https://github.com/Pyre540/tinkers-levelling-addon)

## Maintenance and Support

I don't intend to maintain these modifications beyond getting them working with my own modpack.

There is no guarantee that the code will work correctly in other environments or with other mod configurations. Please don't expect support or fixes from me, and please don't direct issues relating to these modifications to the original developer.

I'm not an experienced Java developer, so some of my implementations may be inefficient, contain bugs or cause unexpected compatibility issues. **Use at your own risk.**
